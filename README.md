# ⚡ TechHub – Electronics E-Commerce Website

TechHub is a modern electronics e-commerce platform built using React and Vite, designed to provide a complete online shopping experience with authentication, product filtering, cart management, wishlist functionality, and a seamless checkout workflow.

## 🌐 Live Demo

https://tech-hub-e-commerce-website-web-dev.vercel.app/

---

## 📌 Project Overview

TechHub allows users to browse electronic products, search and filter items, manage wishlists and shopping carts, authenticate accounts, and place orders through a simulated checkout process.

The project was developed as an advanced Web Development Internship Project to demonstrate modern frontend architecture, state management, responsive design, and e-commerce functionality.
